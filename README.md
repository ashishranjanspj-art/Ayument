# AyuMent

AyuMent is an Ayurvedic digital health platform focused on mental wellness.

## Vision
To make authentic Ayurvedic mental healthcare accessible through technology.

## Modules

- Prakriti Assessment
- Manas Prakriti Assessment
- Mental Health Screening
- Doctor Consultation
- Personalized Ayurvedic Treatment
- AI Assisted Guidance
